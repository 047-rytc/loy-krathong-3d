# 🪷 เทศกาลลอยกระทง 3D (Loy Krathong Festival 3D)

เว็บแอปพลิเคชัน 3 มิติ จำลองบรรยากาศงานวัดริมแม่น้ำเจ้าพระยาในคืนวันเพ็ญเดือนสิบสอง พัฒนาด้วย **Three.js** และ **Vite**

## ✨ ฟีเจอร์หลัก (Key Features)

### 1. บรรยากาศคืนวันเพ็ญริมแม่น้ำ (Atmosphere & River)
- **พระจันทร์เต็มดวงและท้องฟ้าดวงดาว:** ดวงจันทร์เรืองรองพร้อมรัศมีแสงนวล (Lunar Halo) บนท้องฟ้าดวงดาวระยิบระยับ
- **ผิวน้ำเจ้าพระยา (Custom Water Shader):** ผิวน้ำไหลกระเพื่อมตามคลื่น Gerstner Waves สะท้อนแสงจันทร์สีเงินและแสงไฟสีทองอร่ามของวัด
- **โคมลอยเรืองแสง (Sky Lanterns):** โคมลอยลอยขึ้นสู่ท้องฟ้าอย่างต่อเนื่อง พร้อมปุ่มกดปล่อยโคมลอยส่วนตัว

### 2. วัดไทยและงานวัดริมฝั่ง (Thai Temple & Carnival)
- **พระอุโบสถทรงไทย:** หลังคาทรงไทยลดหลั่น 3 ชั้น ยอดจั่วประดับช่อฟ้า เสาพาไลสีขาวหินอ่อน และแสงไฟสีทองส่องสว่าง
- **พระเจดีย์สีทองอร่าม (Golden Chedi):** องค์ระฆังคว่ำสีทองสะท้อนเงาโลหะ พร้อมสปอตไลท์สีทองส่องประกายขึ้นสู่ยอดเจดีย์
- **ชิงช้าสวรรค์เรืองแสง (Ferris Wheel):** หมุนได้จริงแบบ 360 องศา ประดับไฟนีออนหลากสีสัน
- **ไฟราวงานวัดและซุ้มร้านค้า:** หลอดไฟราวโค้งระยิบระยับและซุ้มขายอาหาร/ขนมไทยริมตลิ่ง

### 3. ระบบประดิษฐ์และลอยกระทง 3D (Customizer & Release)
- **ปรับแต่งกระทงได้ตามใจชอบ:**
  - ฐานกระทง: ใบตอง, ขนมปังรักษ์โลก, หรือน้ำแข็งเรืองแสง
  - สีดอกไม้: ดอกดาวเรือง (สีเหลือง), ดอกบัว (สีชมพู), ดอกกล้วยไม้ (สีม่วง)
  - เครื่องสักการะ: ธูป 3 ดอก, เหรียญมงคล (ทอง/เงิน), เปลวเทียนหลากสี
  - พิมพ์ชื่อและคำอธิษฐานขอขมาพระแม่คงคา
- **แอนิเมชันลอยกระทง:** วางกระทงลงน้ำอย่างนุ่มนวล จุดเทียนสว่างไสวพร้อมประกายไฟกะพริบ แล้วลอยล่องตามกระแสน้ำ
- **โหมดตามติดกระทง:** กล้องลอยตามกระทงของคุณอย่างใกล้ชิด

### 4. ซุ้มมินิเกมงานวัด (Temple Fair Mini-Games)
- 🎯 **ซุ้มปาโป่ง:** ปาลูกดอก 5 ดอกตามวิถีโค้ง สะสมคะแนนเพื่อปลดล็อกของแต่งกระทงแรร์ **"ดอกบัวทองคำ (Golden Lotus)"**
- 🌊 **ซุ้มสาวน้อยตกน้ำ:** ปาลูกบอล 3 ลูกเข้าเป้าสีแดงเพื่อให้แท่นพับและตัวละครตกน้ำตูมสนั่น ปลดล็อก **"มงกุฎจิ๋วมงคล"** และ **"ออร่าประกายแสงสวรรค์"**

### 5. ลูกเล่นเสริมและเสียงบรรเลง
- 🎆 **จุดพลุบนฟ้า:** คลิกตรงไหนก็ได้บนท้องฟ้าเพื่อยิงพลุระเบิดประกายไฟหลากสีสัน
- 🪷 **ส่องอ่านคำอธิษฐาน:** นำเมาส์ไปชี้หรือคลิกที่กระทงใบใดก็ได้ในแม่น้ำเพื่ออ่านป้ายชื่อและคำขอพร
- 🎵 **เสียงดนตรีคู่:** เสียงระนาดเอกบรรเลงเพลงวันเพ็ญเดือนสิบสอง และเสียงบรรยากาศสายน้ำ/กระดิ่งวัด (Web Audio API)

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Getting Started)

1. **Clone repository:**
   ```bash
   git clone https://github.com/mac29/loy-krathong-3d.git
   cd loy-krathong-3d
   ```

2. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

3. **รัน Development Server:**
   ```bash
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่ `http://localhost:5173/`

4. **Build สำหรับ Production:**
   ```bash
   npm run build
   ```

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- [Three.js](https://threejs.org/) - 3D Graphics Library
- [Vite](https://vitejs.dev/) - Next Generation Frontend Tooling
- WebGL & GLSL Shaders - Custom Wave Water Shader & Bloom Post-processing
- Web Audio API - Sound Synthesis for Melody, Ambiance, and Mini-Games
